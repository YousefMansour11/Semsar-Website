# Semsar Web

Public-facing real estate website for Semsar. Built with React, TypeScript, Vite, and Tailwind CSS.

## Setup

```bash
npm install
npm run dev     # http://localhost:8080
npm run build   # production build
```

## API

Base URL configured via `VITE_API_BASE` env var (defaults to `http://semsar-hub.runasp.net`).
